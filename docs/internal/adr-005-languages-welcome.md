# ADR-005. Языки интерфейса и приветственный документ

- Статус: принято автором 2026-11-04
- Дата: 2026-11-04

## Контекст

Тексты folio жили константами в коде (`TEXT` окна, `LABELS` главного
процесса, `TEXT` печати) на двух языках, язык — только по системе. Новый
язык требовал правки кода. Знакомства с возможностями не было: пустое окно
с подсказкой «откройте файл».

## Решения автора

| № | Вопрос | Решение |
|---|---|---|
| 1 | Приветствие | **встроенный документ только для чтения** на языке интерфейса: что умеет folio, с живыми примерами (схемы, таблицы, задачи, формулы, канбан, календарь, API, BPMN…); открывается при первом запуске и командой «Справка → Возможности folio» |
| 2 | Как добавлять языки | **JSON на язык**: `en` — базовый, `ru` — второй, оба встроены; чего нет в переводе — берётся из английского; свой язык — `folio-data/locales/<код>.json` без пересборки; проверка полноты переводов — тестом |
| 3 | Выбор языка | **язык системы по умолчанию** (если он есть, иначе английский) **+ переключатель** в меню настроек; применяется сразу, запоминается |

## Устройство

- `src/locales/<код>.json`: `meta` (код, название на самом языке), `main`
  (меню и диалоги), `window` (окно), `print` (печать). Формы числа — массив
  форм, как в `Intl.PluralRules`.
- Главный процесс — источник словаря: английский, поверх — выбранный язык
  (встроенный или из `folio-data/locales`), окну — его разделы; смена языка
  перестраивает меню и шлёт окну новый словарь.
- Виджеты (`embed`) получают тот же код языка; чего кит не знает — английский.
- Приветствие: `src/welcome/<код>.md`, своё для языка, иначе английское.
