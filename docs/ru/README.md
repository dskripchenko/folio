# folio

Настольное приложение, чтобы читать, править и печатать Markdown с живыми
схемами, справочниками API и конструкторами — на macOS, Windows и Linux, без
установки.

> Статус: **1.5** — архив для вашей системы — в [последнем выпуске](https://github.com/dskripchenko/folio/releases/latest).

- [Как устроено](design.md) — окна, что может документ, где лежат данные
- [Разработка](development.md) — сборка, запуск и тесты

## Рядом с системой

- Без установщика и прав администратора: zip на Windows и macOS, AppImage на
  Linux.
- Настройки, кэши и состояние окон лежат в `folio-data/` рядом с программой;
  удалили папку — folio удалён полностью.
- Документу не доверяют: он видит только свою папку и ходит в сеть только с
  вашего согласия.
