# folio

Настольное приложение, чтобы читать, править и печатать Markdown с живыми
схемами, справочниками API и конструкторами — на macOS, Windows и Linux, без
установки. А ещё лёгкая IDE для работы рядом с ИИ-агентом в терминале: его
изменения — как пулл-реквест, то, что изменилось с последнего просмотра, его
worktree, замечания прямо в его консоль.

> Статус: **1.18** — архив для вашей системы — в [последнем выпуске](https://github.com/dskripchenko/folio/releases/latest).

- [Как устроено](design.md) — окна, что может документ, где лежат данные
- [Разработка](development.md) — сборка, запуск и тесты

## Рядом с системой

- Без установщика и прав администратора: zip на Windows и macOS, AppImage на
  Linux.
- Настройки, кэши и состояние окон лежат в `folio-data/` рядом с программой;
  удалили папку — folio удалён полностью.
- Документу не доверяют: он видит только свою папку и ходит в сеть только с
  вашего согласия.

## Рядом с терминалом shell

Когда на компьютере есть и терминал [shell](https://github.com/dskripchenko/shell),
они находят друг друга: shell открывает в folio файлы, проекты и ревью; folio
открывает вкладку в shell, отправляет замечания ревью в панель агента там и
берёт для консолей цвета shell; журнал того, какой агент что правил, у обоих
один. Подробнее — *Рядом с терминалом shell* в [Как устроено](design.md).
